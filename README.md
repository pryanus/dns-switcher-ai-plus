# DNS Switcher AI+

Windows-приложение для подбора DNS/SNI-маршрутов к AI и повседневным сервисам. Тёмный интерфейс, избранное, связанные домены и системный трей.

![Интерфейс](docs/screenshot.png)

## Скачать

Portable EXE: [Releases](https://github.com/sasha59/dns-switcher-ai-plus/releases/latest). Установка не требуется; Windows запросит права администратора.

Избранное: Spotify, ChatGPT, Gemini и Claude. Крестик скрывает окно в трей. Полный выход — через меню значка приложения.

## Использование

1. Нажмите **Подобрать**. Проверяются TCP, сертификат TLS, HTTP, признаки GEO-запрета и связанные узлы входа/API/файлов.
2. Откройте сервис и проверьте вход, сообщение, файл или воспроизведение. Нажмите **Работает** после проверки нужных функций.
3. Одна синяя кнопка сверху карточки подбирает другой маршрут, пропуская текущие и отклонённые IP. Сброс пропусков — в деталях.

Есть звёздочки избранного, скрытие/возврат сервисов, параллельные проверки с отменой, обновление баз, настраиваемый фоновый мониторинг и защита от повторного запуска.

Провайдеры: GeoHide RU/EU/US, MALW DNS, Zapret DNS, DNS-AI и пользовательские. **Проверить** не записывает hosts. **Подобрать** добавляет проверенные адреса в отдельные блоки, сохраняет исходные строки и создаёт резервную копию. DNS адаптера не меняется. Настройки и резервные копии остаются локальными.

## Ограничения

DNS/SNI не заменяет VPN или обход DPI, не меняет регион аккаунта, не предоставляет подписку и не доказывает работоспособность всех функций по открывшейся главной странице. Зелёный статус — подтверждение пользователя.

YouTube и Discord присутствуют в каталоге с пометкой о необходимости отдельного обхода DPI. Для Netflix, Disney+, Prime Video, HBO Max, Hulu, Paramount+ и TIDAL обход текущим пулом не подтверждён: приложение сообщает об этом и не подменяет hosts.

Hosts не поддерживает wildcard; новые динамические адреса файлов требуют обновления базы. Сторонние записи с другими IP могут конфликтовать: строка выше не гарантирует приоритет. Во время записи завершите запрос UAC; отмена сохраняет уже завершённые применения.

## Исходники и сборка

Windows, Python 3.12+:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src\main.py
.\.venv\Scripts\python.exe -m unittest discover -s tests
.\.venv\Scripts\python.exe build_exe.py
```

Сборка создаёт `dist/DNS_Switcher.exe` с запросом прав администратора. Тесты используют временные hosts и подменённую сеть.
