# DNS Switcher AI+ 1.1.1

Windows-приложение для подбора DNS/SNI-маршрутов к ChatGPT, Gemini, Claude, Spotify, Google Antigravity, Grok, DeepL и другим сервисам. Тёмный интерфейс, избранное, связанные домены и системный трей.

![Интерфейс](docs/screenshot.png)

## Что нового в 1.1.1

- **Добавлены встроенные DoH-резолверы Cloudflare (`1.1.1.1 / 1.0.0.1`) и Quad9 (`9.9.9.9`):** работают вместе с Google Public DNS для получения чистых неподменённых IP в обход DNS-спуфинга интернет-провайдера и для проверки режима «Прямое подключение».
- **Исправлен подбор DNS для Claude, Grok, DeepL и ChatGPT:** устранены ложные отказы из-за антибот-ответов Cloudflare при проверке через Python; добавлены реалистичные навигационные заголовки браузера, корректная проверка поддоменов (CDN/API/авторизации) и распознавание `HTTP 451` (DeepL) как регионального ограничения.
- **Режим «Прямое подключение / Системный DNS» (без hosts):** для сервисов, работающих напрямую без проксирования (Camel AI, Make.com, Trae.ai, Adobe / Firefly, Hume AI, Framer), программа автоматически проверяет прямой маршрут, очищает старые нерабочие записи `hosts` этого сервиса и сохраняет прямое подключение без засорения `hosts`.
- **Обновлён каталог сервисов:**
  - В избранном по умолчанию: **Spotify, ChatGPT, Gemini, Claude**.
  - Добавлены: **Google Antigravity**, **Grok**, **Trae.ai**, **Camel AI**, **Hume AI**, **Adobe / Firefly**, **DeepL**, **Make**, а также популярные в РФ сервисы (**Microsoft Copilot**, **Google AI Studio & NotebookLM**, **Groq**, **NVIDIA AI**, **JetBrains**, **CapCut**, **Slack**, **Atlassian**).

## Использование

1. При запуске приложение проверяет активные записи избранного в hosts без изменения файла. Если главная страница и критичные API отвечают, показывает **Маршрут отвечает** и сохраняет его, независимо от провайдера. **Подобрать** также сначала проверяет текущий маршрут.
2. **Маршрут отвечает** означает доступность проверенных сетевых узлов. Без авторизации приложение не доказывает работу функций аккаунта. Кнопка ручного подтверждения удалена. Подозрительный трафик и региональные ошибки исключаются из успешного подбора. Cloudflare challenge исключается из применения при любом способе подбора, включая «Другой маршрут» и ручной выбор. Обычное подключение Turnstile или разрешение Cloudflare в CSP страницы не считается блокировкой. Редиректы проверяются до конечного ответа, даже если их код указан в профиле сервиса.
3. Большая кнопка **Другой маршрут** явно запускает смену адреса и перебирает пул по кругу. Сначала проверяется пригодность. GeoHide имеет приоритет перед другими провайдерами; задержка сравнивается внутри одного приоритета. Состояние провайдеров и регионов сохраняется при обновлении; выключенные EU/US не включаются автоматически. Рабочий активный DNS ради меньшего отклика самопроизвольно не меняется. После полного круга ранее пропущенные IP снова доступны, кроме активного адреса. Карточка показывает старый и новый IP, число проверенных адресов и размер пула. «Подробнее» содержит список кандидатов. Если альтернативы нет, текущий маршрут сохраняется и это явно сообщается. **Начать пул сначала** в деталях сбрасывает выбор и начинает подбор с GeoHide по приоритету провайдеров. DNS-AI можно отключить в настройках провайдеров.

В настройках на вкладке **Обновление** можно проверить GitHub и скачать/установить новую стабильную версию. Файл проверяется по SHA-256; EXE заменяется после завершения приложения, предыдущая версия сохраняется рядом. Системный hosts и настройки обновлением не перезаписываются.

Избранное и каталог не пересекаются. В каталоге кнопка **Подобрать всем** обрабатывает только каталог, не затрагивая избранное; **Проверить** следует тому же правилу. В избранном — **Подобрать избранному**. Синяя **Подобрать** на карточке действует только на один сервис; **Подробнее** открывает диагностику. Восстановленные сервисы больше не очищаются из hosts при запуске. Явно добавленные пользователем сервисы сохраняются. Техническая доступность маршрута не доказывает работоспособность аккаунта.

**Сбросить DNS** виден прямо на карточке сервиса без раскрытия деталей. **Сбросить DNS всех сервисов** виден внизу настроек на любой вкладке. Сброс удаляет исключительно блоки DNS Switcher и возвращает исходные записи; перед изменением создаётся бэкап. Исходные строки выбранных доменов временно отключаются, чтобы Windows не возвращала старые IP вместе с выбранным. Они сохраняются в помеченных комментариях внутри hosts и восстанавливаются при сбросе, включая кодировку и окончания строк. Другие домены на общей строке продолжают работать. DNS адаптера не меняется.

Обязательные и дополнительные домены проверяются по общему пулу всех включённых источников, поддерживающих конкретное имя. Маршрут может объединять провайдеров для разных доменов. Ошибка одного IP не отклоняет остальные адреса провайдера. Каждый IP получает собственный таймаут; общий бюджет больше не обрывает последующие волны. HTTPS-редиректы проверяются на адресах нового имени с обязательной проверкой TLS. В деталях сохранены источники дубликатов, результаты по доменам, пропущенные нативные ответы и возраст кэша. Каталог сверяется тестами с опубликованными hosts GeoHide/MALW и списком сервисов Zapret; это означает заявленную поддержку, а не подтверждение всех функций аккаунта. GeoHide предоставляет по 15 адресов для ChatGPT и Gemini; кандидаты не ограничены двумя IP. База MALW входит в EXE и обновляется из официального источника.

Есть звёздочки избранного, скрытие/возврат сервисов, параллельные проверки с отменой, обновление баз, настраиваемый фоновый мониторинг и защита от повторного запуска.

Провайдеры: GeoHide RU/EU/US, MALW DNS, Zapret DNS, DNS-AI, Google Public DNS и пользовательские. Google Public DNS — обычный резолвер через официальный DoH для сравнения: его адреса и совпадающие с ними нативные IP других резолверов исключаются из пула GEO-обхода. **Проверить** не записывает hosts. **Подобрать** добавляет проверенные адреса в отдельные блоки, сохраняет исходные строки и создаёт резервную копию. DNS адаптера не меняется. Блоки сервисов разделены пустыми строками, IP и домены выровнены пробелами. Настройки и резервные копии остаются локальными.

## Ограничения

DNS/SNI не заменяет VPN или обход DPI, не меняет регион аккаунта, не предоставляет подписку и не доказывает работоспособность всех функций по открывшейся главной странице. Старые результаты не показываются как текущая доступность. После новой проверки появляется краткий нейтральный результат; техническая диагностика доступна только в «Деталях», без всплывающего отчёта.

Netflix, Prime Video, HBO Max, Hulu и TIDAL исключены из стандартного каталога: обход текущим пулом не подтверждён.

Hosts не поддерживает wildcard; новые динамические адреса файлов требуют обновления базы. Строка выше не гарантирует приоритет: при применении программа временно отключает прежние записи выбранных доменов, сохраняя их для точного восстановления. Если сохранённый блок отредактирован вручную, запись останавливается без потери этих правок. Во время записи завершите запрос UAC; отмена сохраняет уже завершённые применения.

## Исходники и сборка

Windows, Python 3.12+:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src\main.py
.\.venv\Scripts\python.exe -m unittest discover -s tests
.\.venv\Scripts\python.exe build_exe.py
```

Сборка создаёт `dist/DNS_Switcher.exe` с запросом прав администратора. Тесты используют временные hosts и подменённую сеть.

## Диагностика

`DNS_Switcher_AI_Plus.exe --diagnose --output diagnostics.json` проверяет Claude, Stitch и Manus тем же алгоритмом подбора через включённые в настройках источники, не меняя системный hosts и настройки. JSON содержит обновление источников, домен, IP, этапы TCP/TLS/HTTP и причину отказа. Обычный подбор также пишет локальный `data/diagnostics/routes.jsonl`. При импорте hosts все IP сохраняются как отдельный источник и доступны после перезапуска.
